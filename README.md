 📚 Book Sales Analysis Dashboard – Tableau

 📌 Project Overview
The Book Sales Analysis Dashboard is an interactive data visualization project developed using Tableau to analyze book sales performance and discover meaningful business insights. It helps understand revenue trends, bestselling books, popular genres, author performance, and customer purchasing patterns.

The dashboard transforms raw sales data into interactive visualizations to support data-driven decision-making.

 🎯 Project Objectives
- Analyze overall book sales and revenue performance.
- Identify top-selling books and popular genres.
- Understand author-wise sales performance.
- Track sales trends over different periods.
- Explore customer purchasing patterns.
- Generate actionable insights through interactive dashboards.

 🛠️ Tools & Technologies
- Tableau – Dashboard development and data visualization.
- Microsoft Excel – Data preparation and cleaning.
- Data Analytics – Exploratory analysis and KPI tracking.

 📊 Key Dashboard Features
- Total Sales and Revenue KPIs.
- Top-selling Books Analysis.
- Genre-wise Sales Performance.
- Author-wise Performance Analysis.
- Sales Trend Analysis.
- Interactive Filters and Visualizations.

 🔍 Key Insights
The dashboard helps identify:
- Which books generate the highest sales.
- Which genres attract more customers.
- Which authors perform best.
- How sales change over time.
- Important patterns in book purchasing behavior.

 🚀 How to Use
1. Clone or download this repository.
2. Download and install Tableau Desktop or Tableau Public.
3. Open the Tableau workbook (`.twbx` or `.twb`).
4. Explore the dashboard using interactive filters and charts.
5. Analyze the sales insights and performance indicators.
